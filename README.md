## ✨ O que tem

| | |
|---|---|
| 📱 **Responsivo** | Menu lateral no celular e navegação fixa no topo |
| 🌙 **Modo escuro** | Alterna entre tema claro e escuro, e lembra a escolha |
| ⌨️ **Efeito de digitação** | Texto animado na apresentação |
| 🧱 **Seções** | Sobre, Experiência, Habilidades e Contato |
| 🎠 **Carrossel** | Tecnologias em destaque |
| 🪗 **Acordeão** | Experiência profissional |
| 🎞️ **Animações** | Entrada suave dos blocos ao rolar a página |
| ⬆️ **Voltar ao topo** | Botão para subir rapidamente |

## 🛠️ Tecnologias

- HTML5 e JavaScript puro
- [Tailwind CSS](https://tailwindcss.com/) via CDN
- [AOS](https://michalsnik.github.io/aos/) para as animações de rolagem
- [Lucide](https://lucide.dev/) para os ícones
- Fonte [Inter](https://fonts.google.com/specimen/Inter)
- Publicado na [Vercel](https://vercel.com/)

## 🚀 Como rodar

Não precisa instalar nada. É um único arquivo:

```bash
git clone https://github.com/joaoalexandre2/portfolio.git
cd portfolio
```

Abra o `index.html` no navegador. Se preferir um servidor local:

```bash
npx serve .
```
